# Walmart Sales Analysis

## 📌 Project Overview

This project focuses on analyzing Walmart sales data using **MySQL** to identify sales trends, customer behavior, product performance, and revenue insights.

The project contains SQL queries that answer various business-related questions using aggregation, filtering, grouping, subqueries, CASE statements, and window functions.

## 🛠️ Tools & Technologies

* **MySQL**
* **SQL**
* **GitHub**

## 📊 Dataset

The dataset contains sales transaction information such as:

* Invoice ID
* Branch
* City
* Customer Type
* Gender
* Product Line
* Unit Price
* Quantity
* Tax
* Total Sales
* Date & Time
* Payment Method
* COGS
* Gross Income
* Customer Rating

## 🔍 Analysis Performed

The project analyzes:

### Generic Analysis

* Number of unique cities
* Branch and city relationships

### Product Analysis

* Number of unique product lines
* Most common payment method
* Best-selling product line
* Monthly revenue
* Month with the highest COGS
* Product line with the highest revenue
* City with the highest revenue
* Product line with the highest VAT
* Product line performance
* Branches selling above average
* Most common product line by gender
* Average rating by product line

### Customer Analysis

* Number of unique customer types
* Number of payment methods
* Most common customer type
* Customer type with the highest number of purchases
* Gender distribution
* Gender distribution by branch
* Highest-rated time of day
* Highest-rated time of day by branch
* Best-rated day of the week
* Best-rated day by branch

### Sales Analysis

* Sales by time of day and weekday
* Revenue generated by customer type
* City with the highest average VAT
* Customer type with the highest average VAT

## 📈 Data Transformation

Additional columns were created to make the analysis more meaningful:

### Time of Day

Transactions were categorized into:

* Morning
* Afternoon
* Evening

### Day Name

The transaction date was converted into the corresponding day of the week.

### Month Name

The transaction date was converted into the corresponding month name for monthly analysis.
